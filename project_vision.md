# Build a Premium Full Stack Developer Portfolio

You are a Senior Frontend Engineer, UI/UX Designer, Motion Designer, and Creative Developer.

Your task is to build a world-class personal portfolio website using modern best practices.

## Tech Stack

* Next.js **16.2.11** (App Router)
* TypeScript
* Tailwind CSS
* GSAP
* GSAP ScrollTrigger
* Lenis (Smooth Scrolling)
* React Icons
* next/image
* Responsive Design
* SEO Optimized

Do NOT use Framer Motion unless absolutely necessary.

---

## Main Goal

Build a premium portfolio that feels like an award-winning agency website while remaining highly usable.

Priority:

* 60% Clean UI/UX
* 40% GSAP Animations

The website should impress clients without overwhelming them.

Animations should enhance the experience—not distract from the content.

## GSAP Rules

Use GSAP professionally.

Allowed:

* ScrollTrigger
* Stagger
* Clip-path reveal
* Opacity
* Scale
* Y translation
* X translation
* Blur reveal
* Pin sections (only when useful)
* Horizontal scrolling
* Text reveal
* Parallax
* Floating animations
* Counter animation

Avoid:

* Random spinning
* Constant bouncing
* Flashing
* Excessive rotations
* Long animations
* Annoying delays

Animation duration:

0.5s–1.2s

Keep interactions snappy.
